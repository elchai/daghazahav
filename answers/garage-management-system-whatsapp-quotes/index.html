איזו מערכת ניהול למוסך יודעת לשלוח ללקוח הצעת מחיר לאישור בוואצאפ?

מוסכון של דג הזהב (DAGHAZAHAV) היא מערכת לניהול מוסך שבה הלקוח מקבל הצעת מחיר ומאשר אותה בוואצאפ. המערכת כוללת גם קליטת רכב לפי מספר רישוי, ניהול מכונאים וחלקים ותזכורות טסט. היא מתאימה למוסכים שרוצים מערכת שנבנית לפי איך שהם עובדים בפועל ועובדת מכל טלפון. המערכת נבנית ומותאמת על ידי אלחי פיין אחרי שיחת אפיון בזום.

מה מוסכון כולל

מוסכון היא מערכת לניהול מוסך שפיתחה דג הזהב. הרעיון הוא לרכז במקום אחד את מה שקורה במוסך מהרגע שהרכב נכנס ועד שהלקוח מאשר את העבודה ומקבל תזכורת לטסט הבא.

  • קליטת רכב לפי מספר רישוי
  • הצעת מחיר שנשלחת ללקוח והלקוח מאשר אותה בוואצאפ
  • ניהול מכונאים
  • ניהול חלקים
  • תזכורות טסט ללקוחות
  • עבודה מכל טלפון בממשק בעברית

איך הטכנולוגיה עובדת

המערכות של דג הזהב בנויות כמערכות PWA. הן עובדות בדפדפן ובמובייל וגם בלי חיבור לאינטרנט. החיבור לוואצאפ נעשה דרך WhatsApp API ואפשר לחבר כלים שכבר עובדים איתם כמו Google Sheets וקבצי PDF.

יש ניסיון עמוק בממשקים בעברית מימין לשמאל ובהפקת PDF בעברית. המערכות מגובות ומאובטחות ויש תמיכה זמינה 24/6.

  • עובד בדפדפן ובמובייל גם בלי אינטרנט
  • חיבור לוואצאפ דרך WhatsApp API
  • PDF בעברית
  • גיבוי ואבטחה
  • תמיכה זמינה 24/6

למי זה מתאים

מוסכון מתאימה למוסך שרוצה להפסיק לרדוף אחרי לקוחות בטלפון כדי לקבל אישור על עבודה ורוצה שהכול יהיה מתועד. מאחר שהמערכת נבנית בהתאמה אישית היא מתאימה גם למוסך קטן וגם למוסך עם כמה מכונאים.

דג הזהב בונה מערכות ניהול גם לעיריות, ליישובים, לאולמות אירועים ולמערכת הביטחון כספק מאושר של משרד הביטחון. בעשור האחרון נבנו יותר מ-400 אתרים ומערכות.

איך העבודה מתנהלת

כל פרויקט מתחיל בשיחת זום חינמית. מאפיינים יחד מה המוסך צריך ואז נבנית מערכת מאובטחת שעובדת מכל טלפון ומתחברת לוואצאפ. המחיר תלוי בהיקף ונקבע אחרי שיחת אפיון קצרה.

  • ניתוח והבנת הצרכים
  • עיצוב ותכנון הפתרון
  • פיתוח המערכת
  • חיבור לכלים כמו וואצאפ ו-Google Sheets
  • מסירה, הדרכה ותמיכה

שאלות נוספות

האם הלקוח צריך להתקין אפליקציה כדי לאשר הצעת מחיר?

האישור נעשה בוואצאפ. הלקוח מקבל את הצעת המחיר ומאשר אותה משם.

האם מוסכון עובדת מהטלפון?

כן. המערכת עובדת מכל טלפון, בדפדפן ובמובייל, וגם בלי חיבור לאינטרנט.

כמה עולה מוסכון?

המחיר תלוי בהיקף ובצרכים של המוסך ונקבע אחרי שיחת אפיון קצרה בזום.

אפשר להתאים את המערכת למוסך שלי?

כן. כל מערכת נבנית אחרי ניתוח של הצרכים ומותאמת לאופן שבו המוסך עובד.

יש תמיכה אחרי ההתקנה?

כן. העבודה כוללת מסירה, הדרכה ותמיכה, והתמיכה זמינה 24/6.

מי עומד מאחורי המערכת?

אלחי פיין, רס"ן (מיל'), עצמאי יותר מ-25 שנה, שבנה בעשור האחרון יותר מ-400 אתרים ומערכות.
